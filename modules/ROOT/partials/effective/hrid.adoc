2+^h|*Hrid*

2+a|A kind of String constrained to obey the syntax of an openEHR human-readable identifier (HRID), used to identify managed knowledge artefacts such as archetypes and templates.

Two identifier forms are recognised: a modern (ADL 2) identifier, which is namespaced and carries a full `major.minor.patch` version, e.g. `org.openehr::openEHR-EHR-OBSERVATION.blood_pressure.v2.1.0`; and a legacy (ADL 1.4) identifier, which has no namespace and a major-only version, e.g. `openEHR-EHR-OBSERVATION.blood_pressure.v2`. The namespace is mandatory in the modern form and absent in the legacy form; `_is_namespaced_` discriminates the two. A namespaceless full-version string is therefore not a valid identifier.

See the openEHR Artefact Identification specification for the grammar, version numbering, concept-identifier semantics and referencing model.
