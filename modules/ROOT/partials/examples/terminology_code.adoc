The ISO 639-1 code for English, as used for the language of an archetype or template.

[tabs%sync]
======
Canonical JSON::
+
The usual form: the terminology and the code.
+
[source,json]
----
{
  "_type": "TERMINOLOGY_CODE",
  "terminology_id": "ISO_639-1",
  "code_string": "en"
}
----

All attributes::
+
Every attribute of `TERMINOLOGY_CODE`, including the optional version and URI.
+
[source,json]
----
{
  "_type": "TERMINOLOGY_CODE",
  "terminology_id": "ISO_639-1",
  "terminology_version": "2002",
  "code_string": "en",
  "uri": "http://id.loc.gov/vocabulary/iso639-1/en"
}
----
