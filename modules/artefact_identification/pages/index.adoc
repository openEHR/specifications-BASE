== Purpose

The purpose of this document is to describe the identification system for openEHR knowledge artefacts, principally archetypes and templates (including operational templates). This includes artefacts created by any organisation, including the openEHR Foundation, standards bodies, clinical modelling initiatives and government programmes.

The semantics covered include:

* formal human-readable and machine identifiers;
* versioning;
* lifecycle management and states;
* referencing artefacts from elsewhere;
* deal with transfer and forking;
* supporting integrity and non-repudiation.

Unless otherwise stated, in this document, the term 'artefact' refers specifically to these artefact types.

The computable type representing a human-readable identifier, `Hrid`, is defined as a primitive type in the openEHR {openehr_foundation_types}[Foundation Types^] specification, and the `ARCHETYPE_ID` and `TEMPLATE_ID` types in the openEHR {openehr_base_types}[Base Types^] specification. The present document is the normative source for the grammar and semantics of these identifiers.
