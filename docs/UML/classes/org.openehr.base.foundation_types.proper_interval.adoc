=== Proper_interval Class

[cols="^1,3,5"]
|===
h|*Class*
2+^h|*Proper_interval<T>*

h|*Description*
2+a|Type representing a 'proper' Interval, i.e. any two-sided or one-sided interval. Its limits may be equal, so a single value such as `1..1` is also a valid `Proper_interval`; `Point_interval` is the compact form of a single value.

h|*Inherit*
2+|`<<_interval_class,Interval>>`
