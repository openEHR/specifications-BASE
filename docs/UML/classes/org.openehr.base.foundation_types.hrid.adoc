=== Hrid Class

[cols="^1,3,5"]
|===
h|*Class*
2+^h|*Hrid*

h|*Description*
2+a|A kind of String constrained to obey the syntax of an openEHR human-readable identifier (HRID), used to identify managed knowledge artefacts such as archetypes and templates.

An HRID has the form `[ namespace '::' ] rm_publisher '-' rm_closure '-' rm_class '.' concept_id '.v' version_id`.

See the _Human-readable Identifiers_ section of the openEHR Foundation Types specification for the full grammar, version numbering and concept identifier semantics.

h|*Inherit*
2+|`<<_string_class,String>>`

h|*Functions*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*is_valid* (): `<<_boolean_class,Boolean>>`
a|True if this identifier conforms to the HRID grammar defined in the openEHR Foundation Types specification.

h|*1..1*
|*is_namespaced* (): `<<_boolean_class,Boolean>>`
a|True if a `_namespace_` is present in this identifier.

h|*1..1*
|*namespace* (): `<<_string_class,String>>`
a|The optional namespace of the identifier, in the form of a reverse domain name, e.g. `"org.openehr"`; empty if this identifier is unnamespaced.

h|*1..1*
|*rm_publisher* (): `<<_string_class,String>>`
a|Identifier of the organisation originating the reference model on which the identified artefact is based, e.g. `"openEHR"`.

h|*1..1*
|*rm_closure* (): `<<_string_class,String>>`
a|Identifier of the reference model top-level package closure on which the identified artefact is based, e.g. `"EHR"`.

h|*1..1*
|*rm_class* (): `<<_string_class,String>>`
a|Name of the reference model class on which the identified artefact is based, e.g. `"OBSERVATION"`.

h|*1..1*
|*qualified_rm_class_name* (): `<<_string_class,String>>`
a|The qualified reference model class name, i.e. `rm_publisher '-' rm_closure '-' rm_class`, e.g. `"openEHR-EHR-OBSERVATION"`.

h|*1..1*
|*concept_id* (): `<<_string_class,String>>`
a|The ontological (domain) concept identifier of the artefact, e.g. `"blood_pressure"`.

h|*1..1*
|*version_id* (): `<<_string_class,String>>`
a|The version part of the identifier as it appears after `'.v'`, e.g. `"1"`, `"1.8.2"` or `"1.8.2-rc.4"`.

h|*1..1*
|*major_version* (): `<<_string_class,String>>`
a|The major version, i.e. the first numeric segment of `_version_id_`, e.g. `"1"`.

h|*1..1*
|*minor_version* (): `<<_string_class,String>>`
a|The minor version, i.e. the second numeric segment of `_version_id_`; empty if not present.

h|*1..1*
|*patch_version* (): `<<_string_class,String>>`
a|The patch version, i.e. the third numeric segment of `_version_id_`; empty if not present.

h|*1..1*
|*version_status* (): `<<_string_class,String>>`
a|The lifecycle status implied by the version modifier: `"alpha"`, `"beta"` or `"release_candidate"` for a pre-release version (`'-alpha'`, `'-beta'`, `'-rc'` respectively), or `"released"` when no modifier is present. These correspond to the `VERSION_STATUS` values defined in the openEHR Base Types specification.

h|*1..1*
|*build_count* (): `<<_string_class,String>>`
a|The build count following a pre-release modifier, i.e. the number in `'-rc.'`, `'-alpha.'` or `'-beta.'`, e.g. `"4"` for `...v1.8.2-rc.4`; empty if no build count is present.
|===
