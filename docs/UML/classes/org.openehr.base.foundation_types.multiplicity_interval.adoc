=== Multiplicity_interval Class

[cols="^1,3,5"]
|===
h|*Class*
2+^h|*Multiplicity_interval*

h|*Description*
2+a|An Interval of Integer, used to represent multiplicity, cardinality and optionality in models. The lower bound is a count: it is always set and never negative. Only the upper bound may be unbounded, written `*`. A single value such as `1..1` is a valid multiplicity.

h|*Inherit*
2+|`<<_interval_class,Interval>>`

^h|*Meaning*

h|*1..1*
|*Multiplicity_unbounded_marker*: `<<_character_class,Character>>{nbsp}={nbsp}'*'`
a|Symbol to use to indicate upper limit unbounded.
